
# 💻 Projeto-C

Este projeto em C reúne uma coleção de programas desenvolvidos para praticar lógica de programação e fundamentos da linguagem C, explorando conceitos como estruturas de controle, funções, arrays e manipulação de dados.

##

## 📌 Sobre o Projeto

O Projeto-C é um repositório que contém diversos exercícios e aplicações escritos em C, com foco em consolidar os fundamentos da linguagem e aplicar lógica de programação em problemas práticos.
Ele serve como um portfolio de estudos e demonstração de evolução técnica em C

##

## 🧠 Tecnologias e Conceitos Utilizados

💻 Linguagem C

🔁 Estruturas de repetição

🔀 Condicionais (if, switch)

🔢 Arrays e manipulação de dados

🧩 Funções

📁 Organização modular de código (quando aplicável)

##

## 📥 Como Executar

### Passos

**1 - Clone o repositório:**

```bash
git clone git@github.com:Ricardo-Brand/Projeto-C.git

```

**2 - Entre na pasta:**

```bash
cd Projeto-C
```

**3 - Compile:**

```bash
make
```

**4 - Execute:**

```bash
make exec
```
